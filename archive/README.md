# Legacy archive

`legacy/` is the complete tracked application tree from commit
`39fe345d362fb860ec2a6968958a65e634af5fa9` before the raw Discord API rebuild.
Paths are preserved relative to the old repository root so endpoint and
behavior parity can be audited. `llms-full.txt` intentionally remains at the
repository root as the active Discord documentation reference.

The archived application is reference material only. It is not loaded by the
new runtime, package scripts, command loader, or tests.
